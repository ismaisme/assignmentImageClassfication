# Image Classification with CNN

This project implements a Convolutional Neural Network (CNN) using Keras and TensorFlow to classify images into two categories: Permitted and Not Permitted.

Features
- Automated Directory Validation: Verifies training and testing folders before execution.
- Image Preprocessing: Resizes varied images to standard dimensions and normalizes pixel values.
- Scalable Model Architectures: Offers three selectable CNN configurations (Simple, Moderate, Complex).
- Performance Metrics: Generates a classification report and visualizes accuracy/loss trends.
